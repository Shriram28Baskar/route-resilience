# Quantitative claim audit

Every number this repository states or displays, classified. Generated by
inspection of the working tree; re-run the audit whenever a figure is added.

**Classification**

| Class | Meaning |
|---|---|
| **MEASURED** | computed from a real input artifact present on disk, reproducible by committed code |
| **DERIVED** | computed from a measured input **plus** constants that are not themselves measured |
| **SYNTHETIC** | produced by a placeholder model with no real input behind it |
| **ILLUSTRATIVE** | a tuning parameter or display threshold; not a claim about the world |
| **UNSUPPORTED** | asserted with no computation behind it anywhere in the repo — **deleted** |

The rule applied throughout: an unsupported number is **removed**, never replaced
with a more plausible one.
